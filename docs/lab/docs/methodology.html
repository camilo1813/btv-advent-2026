METHOD

Compare one change at a time

Start with the controls and keep device, network, app version and distribution context fixed between runs.

Controls and cache

The reference animation has 150 frames at 30 FPS over five seconds. Each frame samples the motion at its frame index divided by 150. The counter resets at the loop boundary. Static and animated assets share the diagnostic palette, layout and motion motifs.

Use the unique canonical URL for each preview case. If the page or asset changes materially, create new versioned paths. Record the manifest's HTML and asset hashes to identify what the device saw. Repeated tests may use a cached preview.

Measure each result separately

Record HTTP availability, browser playback, preview rendering, native media, autoplay, looping, forwarding and quality as separate dimensions. Preview animation and playback after opening a website are separate observations. Simulated crawler requests verify HTTP responses.

Meta documents static Open Graph head fields and thumbnail limits of under 600 KB, at least 300 pixels in width and at most a 4:1 width-to-height ratio. A file outside the baseline is a separate condition. Video metadata, animated previews, Twitter Player Cards, Schema.org and oEmbed are experimental for ordinary WhatsApp. Meta link preview documentation · Open Graph protocol

Sharing and playback

The WhatsApp text-share link opens a manually controlled composer. File sharing requires support from the browser, operating system and chosen share target. Record what the target actually accepts and whether it preserves captions. Web Share · canShare

For phone procedures, see manual tests. Reference material includes WhatsApp GIF help and WhatsApp Status help. Rendering and hosting references include FFmpeg and GitHub Pages limits.

Import approved character media

Place approved derivatives under assets/characters/ and add an entry to the character manifest's assets array. Use lab-relative paths and record the approval in the entry's approval field along with the source, version and intended action. Put the intended primary rendition first and provide a still fallback for alpha video.

The browser accepts still, animated-webp, alpha-webm, alpha-video, opaque-mp4, png-sequence and sprite-sheet. PNG sequences use a frames array and a frame rate. Sprite sheets use frameWidth, frameHeight, frameCount, columns and a frame rate. The promotional MP4 renderer uses approved PNG stills or sequences. The source Blender master stays in the production asset library.

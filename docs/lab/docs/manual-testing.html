Methodology

MANUAL PROTOCOL

Test on your phone

Start on your actual Android phone. Repeat on a second Android, iPhone, WhatsApp Web and Desktop where available.

First ten tests

Run link cases after the lab is public. Use a self chat first and send each case manually.

  1. A01 landscape JPEG establishes the preview control and expected crop.
  2. A02 portrait JPEG checks how the vertical frame is cropped.
  3. A06 animated GIF checks whether the visible frame counter moves in the preview.
  4. A07 animated WebP compares an alternative animated image.
  5. B03 JPEG and MP4 metadata checks play affordances and the destination on tap.
  6. C02 five-second MP4 checks for a GIF conversion option, autoplay and repeated looping.
  7. C03 six-second MP4 repeats C02 at the duration boundary.
  8. C07 standalone GIF tests the original GIF through the native picker.
  9. C09 silent MP4 with URL caption tests manual attachment and caption clickability.
  10. E05 forwarding and Status checks what survives a forward and direct Status posting.

Record setup

Note device model, OS and WhatsApp versions, browser and version, network, media auto-download, data saver, link previews and reduced motion. Create a separate observation for each sender or recipient, client and context.

Use your self chat, a consenting recipient, a private group, Status, a forwarded personal chat or a forwarded group message. Keep initial testing out of public congregation groups.

Link previews

  1. Copy the unique case URL and paste it into the composer. Wait approximately 10 seconds and log generation and preview size.
  2. Send manually. Observe the sent message before tapping and note the correct asset, play button, motion and autoplay.
  3. If the counter moves, watch for three loops. Tap once and record inline playback, the in-app browser or the external browser.
  4. Forward to a consenting recipient, repeat as the recipient, and save sanitised evidence locally.

Native attachments and Status

  1. Download the file. Attach from the ordinary WhatsApp picker. Try the GIF conversion option on the five-second MP4 when offered. Test the original GIF separately.
  2. Where the case requires it, copy the portal URL into the caption and send manually. Record inline or full-screen playback, tap requirement, loop count, audio, crop, quality, caption preservation and link clickability.
  3. Repeat with 3, 5, 6, 10, 15 and 30 seconds. Forward the result and compare the recipient's playback.
  4. For Status, try the media attachment, URL alone and link preview independently. Record caption URL clickability on the actual viewing device.

Evidence

Remove names, numbers, contact photos, chat text and notifications before attaching evidence. Evidence files stay in the current browser. Exports contain observations and evidence filenames. Export individual sanitised clips or screenshots from the observations list when needed.
